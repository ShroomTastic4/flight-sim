✈️ Flight Sim Prototype

A simple 3D flight simulator made with Three.js.

✅ Live demo (GitHub Pages):
https://shroomtastic4.github.io/flight-sim/

No installation needed — works in any modern browser.

🕹️ Controls

W / Up Arrow — Pitch Down

S / Down Arrow — Pitch Up

A / Left Arrow — Turn Left

D / Right Arrow — Turn Right

Spacebar — Speed Boost

Mouse - Rotate camera around the player.
